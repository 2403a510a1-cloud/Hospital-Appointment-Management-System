\# Hospital Appointment Management System



A simple hospital appointment management system developed using Git collaboration practices.



\## Modules



\- Patient Registration

\- Doctor Management

\- Appointment Scheduling

\- Appointment History

\- User Interface



\## Technologies



\- HTML

\- CSS

\- JavaScript

\- Git

\- GitHub



\## Git Collaboration



The project demonstrates:



\- Git repository management

\- Feature branches

\- Multiple developers

\- Multiple commits

\- Remote repository synchronization

\- Branch merging

\- Merge conflict creation and resolution
